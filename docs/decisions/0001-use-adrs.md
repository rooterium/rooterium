# 0001: Use ADRs

- Status: accepted
- Date: YYYY-MM-DD

## Context

The website will be maintained by a small team over several years. People
joining later should be able to understand why things are built the way they
are.

## Decision

Fundamental decisions are recorded as short Markdown ADRs in
`docs/decisions/` (context – decision – consequences).

## Consequences

Little effort per decision; documentation is versioned alongside the code.
Changing a decision requires a new ADR.
